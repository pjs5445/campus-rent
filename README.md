# CampusRent

**이용 목적에 맞는 교내 시설·장비 추천 및 대여·예약 관리 시스템**

> 정보시스템프로젝트캡스톤디자인 | New-Era 팀  
> 분석·설계 문서를 기반으로 실제 시스템 구현을 준비하는 프로젝트입니다.

## 1. 프로젝트 소개

CampusRent는 학생이 필요한 교내 시설·장비를 **직접 검색**하거나, **활동 목적과 참여 인원 등에 맞는 추천**을 받아 적합한 자원을 선택하고 대여·예약을 신청할 수 있도록 지원하는 웹 기반 정보시스템입니다. 관리자는 신청 승인·거절, 장비 출고·반납, 시설 이용 상태 등을 관리합니다.

**핵심 차별점은 목적 기반 탐색입니다.** 예를 들어 학생이 '학생회 회의 6명' 또는 '과제 영상 촬영'을 입력하면, 등록된 용도·키워드·인원 조건에 따라 적합한 공간과 장비, 추천 이유를 안내합니다. 필요한 자원을 이미 알고 있다면 이름이나 분류로 직접 검색할 수도 있습니다.

> 목적별 추천은 현재 계획서상 **규칙 기반**이며 별도의 AI 추천 모델을 사용하지 않습니다. 실제 학교 자원 및 운영 정책은 확인이 필요한 부분이 있고, 현재 시연 데이터에는 가상 시설·장비가 포함됩니다.

## 2. 프로젝트 목표

- 이용 목적과 인원에 맞는 시설·장비를 추천하고 추천 이유를 제시
- 시설·장비 직접 검색, 상세 정보 및 이용 조건 확인 지원
- 이용 불가 시 다른 일정 또는 대체 시설·장비 조회 지원
- 선택 목록에서 필요한 항목과 조건을 확인한 뒤 개별 신청
- 관리자 승인·거절, 장비 출고·반납·점검 및 시설 이용 이력 관리

## 10. 실행 및 DB 기능 확인

JDK 8 이상에서 저장소 루트를 기준으로 실행합니다. 로컬 DB 설정은
[Oracle 연결 안내](docs/development/oracle-setup.md)를 참고하세요.

```powershell
.\mvnw.cmd spring-boot:run
```

[http://127.0.0.1:8080](http://127.0.0.1:8080)에서 학생 회원가입 후 신청할 수 있습니다.
관리자 로그인 정보는 Git에서 제외된 `config/admin-login.txt`에 있습니다.
예전 공개 시연 계정은 실제 DB 계정으로 등록하지 않았습니다.
회원과 업무 데이터는 새로고침·서버 재기동 후에도 DB에 남으며, 서버 재기동 후에는 다시 로그인합니다.

```powershell
.\mvnw.cmd test
.\mvnw.cmd -Poracle-it verify
node tools/check-ui.mjs
```

Oracle 통합 검사는 테스트 데이터를 생성한 뒤 롤백하거나 테스트 데이터만 정리합니다.
최초 DB 설치는 이미 완료했습니다. ERD 원본의 테이블명과 `SEQ_` 시퀀스 규칙을 사용합니다.
자세한 구현·검증 범위와 브라우저 자동 검증 제한은 [설정 기록](docs/development/oracle-setup.md)에 있습니다.
`preview.cmd`는 정적 파일 확인 전용이며 DB 기능에는 Spring Boot 서버가 필요합니다.
