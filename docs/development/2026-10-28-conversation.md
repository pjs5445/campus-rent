초기 `docs/ui/README.md`에는 화면 코드 작성과 검증이 완료됐다는 설명이 있었지만, 당시 저장소에는 해당 `src/`, 미리보기 실행 파일, 검증 코드가 없었습니다.

사용자가 이것이 루트 README 8번의 진행 현황을 뜻하는지 확인했고, 문제가 된 설명은 **`docs/ui/README.md`의 ‘현재 구현’과 ‘검증’ 항목**이라고 구분했습니다. 이후 실제 화면 작업 결과와 검증 범위에 맞게 해당 문서를 수정했습니다.

## 4. 화면부터 개발

사용자 요청은 UI 폴더의 Figma Make 압축파일을 보고, 루트 README의 개발 스펙에 맞춰 화면부터 구현하는 것이었습니다.

수행한 작업:

- ZIP의 React·TypeScript 원본, 자원 데이터와 업무 로직을 확인했습니다.
- 홈, 장비·시설 검색, 목적별 추천, 선택 목록, 시연 로그인, 신청 현황·과거 내역, 관리자 처리 화면을 HTML·CSS·JavaScript로 작성했습니다.
- 원본 SVG 14개와 로컬 폰트 3개를 사용했습니다.
- 장비 7개·시설 5개 및 추천·가용성·대체 조회 로직을 전환했습니다.
- 개별 신청, 승인·거절, 시설 이용 시작·종료, 장비 출고·반납 검수·보류·추가 반환·점검의 로컬 시연 흐름을 연결했습니다.
- `src/main/resources/templates/`와 `static/`에 화면을 배치하고 Thymeleaf 자원 경로 속성을 준비했습니다.
- Java 기반 정적 미리보기 서버와 `preview.cmd`를 추가했습니다.
- 루트 README에 실제 폴더 구조, 진행 현황, 실행 방법과 시연 계정을 기록했습니다.

이 단계에는 Spring Boot 애플리케이션 설정·컨트롤러·실제 Thymeleaf 엔진 실행·Oracle 연결이 포함되지 않습니다. 로그인·신규 가입 계정은 메모리, 선택 목록은 sessionStorage, 가상 신청·검수 기록은 IndexedDB를 사용하는 화면 시연입니다.

- 로컬 JDK 8로 미리보기 서버 컴파일·실행 확인.
- JavaScript 6개 모듈 구문 확인 및 공통 로직 모듈 가져오기 확인.
- 7개 페이지 경로와 인원 포함 추천 경로의 HTML 생성 확인. DOM 대체 객체를 사용했으며 실제 화면 렌더링 검사는 아닙니다.
- 추천·일정·소유권·중복 승인·구성품 검수·시연 인증 로직 검사 23개 통과.
- 페이지·CSS·JavaScript·SVG·폰트 31개 HTTP 경로 응답 확인.
- 브라우저 제어 도구가 Windows의 현재 URL을 확인하지 못해 실제 렌더링·클릭 흐름·모바일 배치 검증은 완료하지 못했습니다.
- 실제 브라우저 IndexedDB 통합과 Spring Boot·Oracle 통합은 미검증입니다.

## 6. Oracle 연동과 미리보기 서버 실행에 대한 사용자 지시

사용자는 **Oracle 데이터베이스를 구축한 뒤 연결용 계정을 제공할 예정**이라고 설명했습니다. 현재 작업은 화면을 개발하고 확인할 수 있도록 하는 단계이며, 화면 확인용 서버를 실행해 달라고 요청했습니다.

이에 `preview.cmd`로 서버를 실행하고 `http://127.0.0.1:8080`의 HTTP 200 응답을 확인했습니다. 사용자 요청에 따라 미리보기 서버를 실행 상태로 유지했습니다. 이는 당시 로컬 실행 상태에 대한 기록이며 GitHub에서 서버가 실행된다는 의미는 아닙니다.

다시 실행할 때는 저장소 루트에서 다음 명령을 사용합니다.

```powershell
.\preview.cmd
```

접속 주소: `http://127.0.0.1:8080`. 포트 변경: `.\preview.cmd 8081`. 종료: `Ctrl+C`.
